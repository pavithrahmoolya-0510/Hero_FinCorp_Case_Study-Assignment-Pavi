# Hero FinCorp Loan Analysis

## Project Overview

This project analyzes loan, customer, transaction, application, default,
branch, and repayment data for Hero FinCorp.

The objective is to identify patterns related to loan performance,
defaults, repayments, profitability, branch efficiency, customer behavior,
risk, and transaction patterns.

## Analysis Performed

1. Data Exploration and Cleaning
2. Loan Portfolio Analysis
3. Transaction Analysis
4. Default and Recovery Analysis
5. Application and Approval Analysis
6. EMI and Default Analysis
7. Branch Analysis
8. Processing Time Analysis
9. Application Rejection Analysis
10. Branch and Loan Analysis
11. Loan Purpose Analysis
12. Profitability Analysis
13. Geospatial Analysis
14. Default Trends
15. Branch Efficiency
16. Time-Series Analysis
17. Customer Behavior Analysis
18. Risk Assessment
19. Time to Default Analysis
20. Transaction Pattern Analysis
